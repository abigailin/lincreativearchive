# the good stuff.
A retro California editorial portfolio for culinary and film photography.

## Add your photography
Replace these files inside `images/` with your own JPG photos, keeping the filenames:
- `coast.jpg` — large homepage film image
- `food.jpg` — homepage food image
- `kitchen-detail.jpg` — Kitchen collection image
- `film-detail.jpg` — Film collection image

Placeholder images are included so the site works immediately; replace them before sharing publicly.

## Customize
- Change `your name` and `hello@example.com` in `index.html`.
- Change colors in `:root` at the beginning of `styles.css`.
- Edit section descriptions in `index.html`.

## Publish on GitHub Pages
1. Create a new public GitHub repository (e.g. `the-good-stuff`).
2. Upload all files and the `images` folder to the repository root.
3. Open repository Settings → Pages → Build and deployment.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
5. Wait for GitHub Pages to publish your site. The URL will typically be `https://YOUR-USERNAME.github.io/the-good-stuff/`.

You can preview locally by opening `index.html` in a browser. No dependencies or build step required.
